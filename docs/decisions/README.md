# Architecture Decision Records

This folder holds short, dated records of notable technical decisions made
during development — the "why," not just the "what."

Not every decision needs one. Use an ADR when a choice was non-obvious,
had a real trade-off, or reversed/refined something in `docs/blueprint.md`.

## Format

`NNNN-short-title.md`, numbered sequentially, e.g. `0001-session-based-auth.md`.

Suggested shape for each file:

```
# 0001 - Short Title

Date: YYYY-MM-DD
Status: Accepted | Superseded by NNNN

## Context
What prompted this decision?

## Decision
What was decided?

## Consequences
What does this affect going forward?
```

No ADRs exist yet — this project is still in the foundation stage.
